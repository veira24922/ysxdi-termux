# YSXDI
YSXDI (Yet Simple XFCE Desktop Installer) is an semi-automated bash script that lets you install XFCE without the need to type too many commands (like me being lazy). This script additionally installs LibreWolf, LibreOffice and Micro *(yeah, this is my favorite editor because it is easier than vim in my opinion).

# Installing
To run the install script, run this bash command:
``cd $HOME && curl -o- "https://raw.githubusercontent.com/veira24922/ysxdi-termux/refs/heads/main/ysxdi-installer.sh" | bash``

The script will ask if you would confirm this installation, then proceed.
